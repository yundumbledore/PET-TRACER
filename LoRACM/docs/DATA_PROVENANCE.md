# Data and model provenance

The four-AIF CSV, Sub001 coronal TAC file, foundation checkpoint and verified slice mask/mapping retain their original contents. The author confirmed the C-order foreground mapping, origin and pixel aspect ratio. Physical millimetre spacing is not supplied.

The original **epoch-2755** adapted model and its x/y normalization are supplied in `paper/ucdavis/`. The checkpoint tensor bytes are unchanged. JSON metadata adds portable paths, parameter names, the explicit time-label convention and the Ki/display policy. `manifest.json` records hashes, original checkpoint filename and provenance limits. Its recorded 100,000 fine-tuning examples follow the author's confirmation, not the current archive row count.

`reference_ki.npz` contains original saved HPC Ki mean/std arrays, with the supplied voxel IDs. `reference_ki.png` renders those arrays with the original 2×2 median filter and fixed 0–0.06 scale. The summary archive has no original draw-level Ki transform metadata. This release explicitly uses the 1e-4 parameter flooring convention found in the original HPC selected-voxel inference code; the checkpoint association follows the author's recollection and current inference source.

New UC Davis training pairs use the original Euler/observation and noise equations with unchanged CSV AIF conditioning, the parameter priors specified in the supplied HPC `Create_dataset.py` and 100,000 training examples. The current generator preserves the source JAX split-key sequence and random-array shapes, including full-split draws before bounded-memory numerical chunking. AIF selection follows the original NumPy RandomState sequence. Sample equality requires matching seed, split sizes, priors, JAX version and PRNG settings; these versions/settings are saved with the dataset. The archived HPC dataset and checkpoint normalization indicate narrower historical ranges (K1/k2 up to about 1.5 and k4 up to about 0.05), whereas the current source uses 2.0 and 0.2. The defaults intentionally follow the current source priors requested by the author; new training is not claimed to reconstruct the archived checkpoint. The older bundled `data/simulated/scenario1.npz` has 50,000 training rows, and is not selected by the paper reproduction route. Use the supplied checkpoint for paper-model inference; retraining across backends is not bitwise reproducible.

The existing MIT software licence is retained. Dataset attribution, activity units/correction conventions, clinical-data reuse terms and model-weight distribution terms should accompany the associated research release. The historical root `MANIFEST.json` describes an earlier inventory; the paper asset manifest describes the new supplied paper model.


## Pretrained Bayesian model-selection demonstration

`model_selection/assets` contains the maintainer-supplied V8TD epoch-1169 EMA checkpoint, original configuration/scaling, P001 FDG coronal-slice-116 TAC/AIF table, slice-only mask and reference map. `manifest.json` records exact asset hashes. The mask is extracted from the original volume as `mask[:, 116, :] == 1`; masked voxel ordering is retained. The full 3-D mask and 406-MB posterior archive are not duplicated in this module. Results are generated locally. The pretrained model's simulation distribution is specific to this protocol/library; the inference-only release does not claim a universal physiological classification of all voxels. See [the module guide](MODEL_SELECTION.md).
